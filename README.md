# 个人学习中心

通用教学方法与个人知识基础分开维护。基础分支可持续增加，调用时明确指定需要使用哪一个。

## 通用技能

[paper-tutor：论文递进学习](skills/paper-tutor/SKILL.md)。将整个 `skills/paper-tutor` 目录复制到 `~/.codex/skills/`。技能本身不默认加载任何学科背景。

## 基础分支

- [生存分析和迁移学习基础](foundations/生存分析和迁移学习基础/README.md)

未来其他基础可并列放入 `foundations/<基础名称>/`，包含简短索引、最新学习进度和必要的历史记录，不需要复制教学技能。

## 调用示例

开始时自动简短回顾所选基础的上次已学、待巩固与本次接续；不自动加载其他基础。

学习中输入 `remember` 即可生成/整合文档并尝试上传后继续；输入 `end` 会整理本次文档、合并进度并尝试上传后结束。每次调用自动呈现对应基础最近一次学习记录，不需要另输状态口令。中文“记一下/收课”仍兼容，“同步学习记录”可恢复待上传。相同主题就地整合，不逐轮复制全文。同步目标为 `jians8420-rgb/learning-skill-for-papers` 的 `main` 分支；在授权范围内同步，失败则保留本地待同步状态。

> 用 $paper-tutor，结合“生存分析和迁移学习基础”，继续第四部分第2.2节似然与估计，每次只推进一个核心问题。

其他电脑可将所需基础目录复制到 `~/.codex/learning-foundations/`，或者在本项目中直接读取。新聊天需要读取所选基础文件，不能仅凭技能名自动获得所有背景。

同步仓库：https://github.com/jians8420-rgb/learning-skill-for-papers ，Git分支为 `main`。个人基础分支使用foundations目录组织，不为每个学科另建Git分支。每次同步结果以已核验提交为准，本地sync-state不纳入远端提交。
